
# COPILOT.md

## 1. Descripción de la aplicación

Este proyecto es un portafolio web profesional desarrollado con Next.js y JavaScript. Su objetivo es presentar mi perfil como estudiante de Ciencias Computacionales, mis conocimientos técnicos, proyectos personales y académicos, y mis medios de contacto.

El portafolio está orientado a oportunidades profesionales, prácticas y primeros empleos en desarrollo de software y áreas de TI.

El sitio cuenta con las siguientes secciones:
- Inicio
- Sobre mí
- Proyectos
- Habilidades (Skills)
- Contacto

## 2. Usuario objetivo

El público principal está conformado por:
- Reclutadores de empresas tecnológicas.
- Profesionales y responsables de equipos de desarrollo.
- Empresas interesadas en perfiles junior y estudiantes para prácticas profesionales.

La información debe ser fácil de localizar, comprender y recorrer. El diseño debe facilitar la identificación de tecnologías, herramientas y competencias.

## 3. Personalidad visual

La personalidad que se busca transmitir es:

- Profesional: apariencia apropiada para un portafolio laboral.
- Moderna: diseño actual, limpio y tecnológico.
- Minimalista: evitar elementos decorativos innecesarios.
- Clara y organizada: jerarquía visual y distribución coherente.
- Accesible: buena legibilidad, contraste y facilidad de navegación.

Se busca un diseño equilibrado que transmita organización, capacidad técnica y atención al detalle, sin parecer excesivamente corporativo.

## 4. Paleta de colores

Se utiliza como referencia la propuesta visual Slate & Emerald.

| Color | Código HEX | Uso |
|---|---|---|
| Fondo claro | #F8FAFC | Fondo principal |
| Texto principal | #0F172A | Títulos y contenido |
| Color de acento | #059669 | Iconos y elementos destacados |
| Bordes | #E2E8F0 | Separadores y tarjetas |

Para el tema oscuro se deben respetar las variables y colores ya definidos en el proyecto. No se debe implementar un sistema de temas nuevo ni modificar globalmente la paleta sin necesidad.

## 5. Contexto técnico

Tecnologías y convenciones del proyecto:

- Next.js con JavaScript.
- Archivos con extensión .js, no .jsx.
- CSS Modules para los estilos de los componentes.
- Diseño Mobile-First.
- Soporte para español e inglés.
- Soporte para tema claro y oscuro.
- Componentes reutilizables de React.
- Navegación y estructura actual de Next.js.

## 6. Sección que se va a rediseñar: Skills

La sección presenta mis habilidades técnicas y blandas.

Las habilidades técnicas están organizadas en cuatro categorías:

1. Desarrollo de software:
   Java, Spring Boot, JavaScript, React, React Native, Next.js, Python, C++, HTML5 y CSS3.

2. Bases de datos:
   MySQL y SQL.

3. Infraestructura, redes y soporte técnico:
   Windows, Linux, Cisco Packet Tracer, Redes de computadoras, Fundamentos de soporte técnico y Fundamentos de ciberseguridad.

4. Herramientas y plataformas:
   Git, GitHub, IntelliJ IDEA, Visual Studio Code, Postman y Swagger / OpenAPI.

Las habilidades blandas se presentan en un apartado independiente:
- Trabajo en equipo.
- Resolución de problemas.
- Aprendizaje continuo.
- Adaptabilidad.

No se deben agregar niveles, porcentajes ni barras de progreso para representar el dominio de las habilidades.

## 7. Objetivos del rediseño

Mejorar la presentación visual de la sección Skills considerando:

- Jerarquía visual clara entre el título, descripción y categorías.
- Distribución equilibrada de las tarjetas.
- Buena legibilidad y contraste accesible.
- Espaciado adecuado entre letras y elementos, e interlineado cómodo.
- Diseño responsivo con enfoque Mobile-First.
- Tipografía coherente con el resto del portafolio.
- Tarjetas visualmente limpias y consistentes.
- Iconos reconocibles y correctamente alineados.
- Separación visual entre habilidades técnicas y blandas.
- Consistencia entre los temas claro y oscuro.

## 8. Restricciones importantes

- No eliminar código o funcionalidades existentes.
- No modificar la información ni los nombres de las habilidades.
- No eliminar el soporte bilingüe.
- No eliminar el soporte de tema claro y oscuro.
- No modificar otras secciones del portafolio.
- No cambiar la estructura de navegación de Next.js.
- No instalar dependencias adicionales sin justificación.
- Reutilizar los componentes existentes siempre que sea posible.
- Mantener los CSS Modules.
- No reemplazar los iconos actuales por elementos decorativos sin justificación.

Antes de implementar cambios, analizar los componentes y estilos existentes.

El objetivo es mejorar el diseño visual sin alterar el comportamiento actual de la aplicación.
